# 拼图工坊 🧩

一个装在 QwenPaw 里的拼图插件：把架构设想拼出来，再用真实插件体验拆装。

## 怎么玩

1. 在「扩展 → 插件」中安装本目录或 ZIP 安装包，刷新控制台。
2. 打开侧栏「🧩 拼图工坊」。中心是不可拆卸的执行核心。
3. 点击 Channels，展开九块频道拼图；拖开、拼回，只演示动画。
4. 点击 Plugins，查看当前实例已安装的插件（包括社区安装的插件）。
5. 拖动拼图，或者选中后点击「拆下 / 拼回」。这些操作只调整草稿。
6. 点击「保存更改」，才真正启停插件。保存后页面自动刷新，更新前端入口。

当前不提供社区市场搜索和下载安装。请先通过 QwenPaw 的插件管理安装，再回到工坊刷新。

## 生效范围

- 插件启停作用于整个当前 QwenPaw 实例，不限于当前 Agent。
- 核心固定；Channels、Browser、Memory、Skills、Models、Schedule、Agents 都只是示意，不更改实际配置。
- 草稿仅在当前页面内保存，刷新或离开页面后丢失。「还原草稿」撤回未保存的拆装。
- 停用保留插件文件与配置，使用宿主支持的 `.disabled` 目录名；可以在工坊里重新启用。
- 宿主原有插件列表可能不展示已停用插件，请在工坊中恢复。卸载工坊前，先将需要的拼图拼回并保存。
- 工坊不能停用自身。未成功加载、目录冲突、链接目录等情况会锁定或跳过，并展示原因。
- 保存会触发宿主 Agent 后台重载，并刷新前端；不承诺立即终止已经运行的任务。

## 实现与兼容

没有修改 QwenPaw 核心。前端通过插件路由注册，后端通过插件 HTTP 路由注册。

实际启停复用宿主 PluginLoader 和安装流程中的运行时同步逻辑。兼容层集中在 `NativeLifecycle`，其中调用了宿主内部函数，因此宿主升级后需要重新验证。当前验证版本是 2.2.2b4；manifest 的最低版本约束不代表所有未来版本都已测试。

保存前检查列表版本，避免覆盖其他页面的变更；与宿主共用插件生命周期锁。批量保存失败时尝试恢复已完成的操作，并返回实际状态及恢复失败信息。插件自行产生的外部副作用不在恢复范围内，不能视为数据库式原子事务。

紧急恢复：停止 QwenPaw 后，在该实例的 `plugins` 目录将 `<插件ID>.disabled` 改回 `<插件ID>`，再启动。只有目标目录不存在时才改名，不要覆盖已有目录。

## 验证

从 QwenPaw 仓库根目录运行：

```sh
.venv/bin/python -m pytest plugins/bundle/puzzle-workshop/tests -q --override-ini='addopts='
node --check plugins/bundle/puzzle-workshop/frontend.js
```

11 项测试覆盖草稿只读、启停保留文件、过期列表拒绝、自身保护、无效 ID、批量失败恢复、启用失败恢复、目录冲突与链接、无变化保存、严格请求校验。

本地浏览器另用一次性测试插件完成：未保存仍响应 → 保存停用后路由 404 → 拼回保存后路由 200。完成后移除测试插件。频道拖拽只改变页面状态，保存按钮保持禁用。未运行 PawBench，也未验证任意第三方插件的全部清理行为。
